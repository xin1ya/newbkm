# 方案：渲染性能 / 野外宝可梦群落 / 霸主刷新机制（待确认）

> 状态：**方案稿，待用户确认后实施**。日期 2026-10-03。
> 背景：RTX 5070 运行时 GPU 占用约 70%；萌芽群岛有大片野区没有宝可梦；希望加入野外霸主级宝可梦（固定点位 + 随机稀有两种都要）。

---

## 一、渲染性能

### 1.1 先说结论：70% 占用不一定是“慢”

当前主循环用 `requestAnimationFrame` **不限帧**。高刷显示器（144 / 165 / 240 Hz）上，GPU 会尽量把每一帧都画出来，所以占用高。真正要看的是：
- 帧时间，目标 p95 ≤ 16.7 ms；
- 在限帧 60 / 120 时 GPU 占用能降到多少。

因此**第一步是测量，不是盲改**。

### 1.2 当前高画质（5070 自动选到 high）的主要开销

| 项 | 当前 high 档 | 估计占比 | 说明 |
|---|---|---|---|
| 渲染分辨率 | `maxPixelRatio 2` | ★★★★★ | 2K/4K 或系统缩放 150% 时按 2× 渲染，像素数是 1× 的 4 倍 |
| MSAA 4× + 后处理链 | RenderPass(MSAA) → Bloom → Grade → Output | ★★★★ | 多重采样渲染目标 + 深度纹理 + 全屏 pass 3–4 次 |
| 阴影 | 4096² 覆盖 65 m，PCF Soft | ★★★ | 每帧把阴影范围内所有物体（含草、树）再画一遍 |
| 草 / 植被 | 1.6 簇/m²，80 m 可见 | ★★★ | 顶点着色器风动 + 过度绘制（overdraw） |
| 水面 full | 法线扰动、焦散、反射高光 | ★★ | 大湖、河、海面全屏覆盖时片元开销大 |
| 远景整岛 + 天空 + 云 | farPlane 2000 | ★ | |
| 野生宝可梦 / NPC 蒙皮 | maxWild 20 | ★ | 骨骼动画 CPU 端 |

### 1.3 优化方向（按收益排序）

**P0：不影响画面观感，先做**
1. **帧率上限设置**：新增设置项“帧率上限：30 / 60 / 120 / 不限”，默认 60。`GameLoop` 按目标帧间隔跳过渲染，固定步逻辑不受影响。这是降低占用最直接的一步。
2. **性能面板（F3 调试层扩展）**：
   - 用 `EXT_disjoint_timer_query_webgl2` 测 GPU 帧时间，并分段统计阴影 / 主场景 / 后处理；
   - 显示 draw calls、三角面、像素比、阴影更新次数。
   - 以后每次优化都用数据说话。
3. **阴影按需更新**：太阳方向每帧只在小幅移动。改为玩家移动超过 2 m 或每 4 帧才重画阴影贴图（`shadow.autoUpdate=false` + `needsUpdate`）。草不投影，只接收；小石头、花不投影。
4. **分辨率上限改为 1.5 + 动态分辨率**：high 档 `maxPixelRatio 2 → 1.5`。连续若干帧超出预算就自动下调 `pixelRatioScale`（0.75–1.0），空闲时回升。
5. **MSAA 与 FXAA 二选一**：关掉描边后不再需要深度纹理和 MSAA。high 档可改为“FXAA / SMAA + 1.5 像素比”，画质接近，开销更低。

**P1：中等改动**
1. **植被 LOD 与距离淡出**：草簇 0–40 m 用全密度；40–80 m 降为 1/3 密度、单面片，并用 `alphaToCoverage` 渐隐，减少过度绘制。树木远处换成两面交叉的 impostor（贴图替身）。
2. **按分块合批**：同一分块里静态物件（栅栏、石头、木箱、路灯杆）合并成一个网格或 `BatchedMesh`，降低 draw calls。
3. **视锥 + 遮挡剔除**：城镇建筑后的物体，可用分块级别的简易遮挡判断（地形高度地平线剔除）。
4. **水面分级**：离相机远的水面使用 simple 着色；焦散只在 30 m 内计算。
5. **Bloom 降为 1/4 分辨率**，并只在夜晚 / 有发光物时开启。
6. **野生宝可梦动画 LOD**：30 m 外动画降到 15 fps 更新，60 m 外停止蒙皮更新（只做位移）。

**P2：长期**
1. 着色器预编译：开场加载时 `renderer.compileAsync`，避免首次进入新区域时卡顿。
2. 画质预设新增“均衡（balanced）”档，作为 5070 这类显卡的自动档位：1.5 像素比、FXAA、阴影 2048 / 50 m、草 1.2 簇/m²。
3. Tauri 桌面版以后可以用原生帧率控制和独显选择。

**预期**：P0 完成后，5070 在 60 帧上限下 GPU 占用预计降到 25–35%；不限帧时帧时间预计下降 30–45%。以 P0 性能面板实测为准。

## 二、野外宝可梦群落

### 2.1 现状

- 岛图 1024 × 1024 m。区域多边形中，野区约 32.5 公顷，城镇约 8.6 公顷。
- **没有被任何区域覆盖的陆地不会刷新宝可梦**，这就是“野区空着”的原因。主要空白如下：
  - 西海岸：萌芽镇以西到沙滩小路，x < −250；
  - 北部丘陵：翠澜镇以北、幻影之森以东，x −110…200，z −170…−440，澜源溪上游在这里；
  - 草原与幻影之森之间的林缘，z −120…55；
  - 东南海岸与翠澜河口，x 300…460，z 160…450。
- 翠澜河谷直接复用湖畔遇敌表，没有自己的特色。
- 现有遇敌只用了约 18 种，同一区域内种类偏少（4–8 种）。

- 潮池：大舌贝；

### 2.4 实施顺序

1. **先用现有 40 种填满新区域**，当天就能玩到不空的野区。
2. 再逐批加入新物种，每批 4–5 种：建模 → 加入 species.json（数据、招式表）→ 遇敌表 → 图鉴。
3. 单测：每个野区遇敌表权重合法；每个物种都有模型或占位；所有物种在时间 × 天气组合下至少有一种可遇到。

## 三、霸主级宝可梦（固定点位 + 随机稀有）

### 3.1 现状

已经有“头目”（`alpha`）基础：
- 遇敌表 `alphaChance 0.02`；
- 等级 +5，个体值固定 25 以上；
- 体型 ×1.35；
- 战斗 HUD 显示 ★，并有红色战斗转场。

缺少的部分：
- 固定点位；
- 刷新周期；
- 视觉威慑（光环、红眼）；
- 行为（主动攻击、领地）；
- 奖励；
- 地图标识；
- 存档记录。

### 3.2 两类霸主

| | **领域霸主（固定点位）** | **游荡霸主（随机稀有）** |
|---|---|---|
| 位置 | 每个野区 1–2 个固定巢穴点（坐标写在区域配置） | 野区内随机刷新，每岛同时最多 1 只 |
| 刷新 | 按**游戏内天数**：击败或捕获后冷却 3 天再刷新；首次进入区域即存在 | 每次刷新判定时有 0.4% 概率，需满足时间 / 天气条件；30 分钟内未遭遇则离开 |
| 物种 | 指定物种（与区域生态相符，可以是该区域进化型，例如草原霸主比比鸟） | 从该区域遇敌表中抽取，排除 rare |
| 等级 | 区域上限 +6~8 | 区域上限 +4 |
| 体型 | ×1.8 | ×1.5 |
| 个体值 | 3 项 31，其余 ≥ 20 | 2 项 31，其余 ≥ 15 |
| 招式 | 携带 1 个“霸主招式”（高于当前等级的招式或蛋招式） | 同左 |
| 行为 | 领地：进入 25 m 范围会警告咆哮，15 m 内主动冲锋；离开巢穴 40 m 会返回 | 主动攻击，视野更远 |
| 战斗 | 开场霸主气场：首回合双防 +1；第一次 HP 低于 50% 时咆哮，攻击 +1 | 开场双防 +1 |
| 奖励 | 首次击败或捕获：专属道具（如“霸主之鳞”，可用于性格薄荷或改个体道具）+ 金钱；之后每次掉落随机道具 | 金钱 + 随机道具 |
| 地图 | 地图上显示红色霸主图标（未发现时显示 ？）；冷却中显示灰色 | 出现时右上角提示“附近有强大的气息……”，地图不标位置 |

### 3.4 视觉表现

- 体型放大，同时身上加一层**红色描边光晕**（只给霸主单独开反向外壳，不影响“取消描边”的全局设定），并加红色眼睛高光。
- 脚下有暗红色地面光圈与粒子，夜晚更明显。
- 移动时会有轻微镜头震动和脚步扬尘，叫声音调降低。

### 3.5 技术落地

- `config/islands/*.ts` 区域新增 `alphaDens: { id, speciesId, level, position, radius, condition?, moves? }[]`。
- `systems/alpha/`（纯逻辑，有单测）负责：
  - 冷却按游戏内天数计算；
  - 判定游荡霸主刷新；
  - 生成个体（个体值、霸主招式）；
  - 结算奖励。
- 存档新增 `state.alpha: { [denId]: { defeatedDay, caught, firstClear } }`，并做旧存档迁移。
- `world/spawns/SpawnManager` 中，领域霸主由单独的槽位刷新，不占 `maxWild`；进入 120 m 内即加载。
- `wildAI` 新增 `territorial` 行为：守卫巢穴，并有警告 → 冲锋两段。
- 战斗层新增开场 / 半血时的能力提升钩子，`BattleHud` 显示“霸主”徽记。
- UI 部分包括：地图图标、宝可梦图鉴“霸主”标签，以及“附近有强大的气息”提示。

## 六、招式机器与想起招式（2026-10-03 补充）

- **招式机器（TM，可重复使用）**
  - 数据：`config/data/tms.json`，记录编号、招式和可学物种。
  - 可学物种按 species 的 learnset 与 TM 表交集生成，并有单测校验。
  - 获取：道馆奖励（翠澜道馆 TM「水之波动」）、商店（港湾大市场卖基础 TM）、野外道具点，以及击败霸主首次掉落。
  - 背包新口袋「招式机器」。使用时先列出队伍里能学的成员，满 4 个招式时走「替换招式」流程。
- **想起招式（找回遗忘的技能）**
  - NPC「想起招式的人」常驻翠澜镇和港湾市宝可梦中心。
  - 费用：1 个「心之鳞片」或 1000 円。心之鳞片来自野外稀有掉落和霸主奖励。
  - 可选招式：当前等级及以下 learnset 中的所有招式，加上进化前形态的招式，排除已会的招式。
  - 进化时错过的招式也能在这里找回。
- **替换招式时显示详情（已完成）**
  - 学新招式（升级 / TM / 想起）时，顶部固定显示新招式详情。
  - 光标移到旧招式时，下方同步显示「将被忘记」的那个招式的详情，可以逐项对比威力、命中、PP、优先度和说明。

    - 鬼斯 → 鬼斯通 → 耿鬼
    - 大舌贝 → 刺甲贝
    - 沙丘娃 → 噬沙堡爷
    - 小拳石 → 隆隆石 → 隆隆岩
    - 腕力 → 豪力 → 怪力
    - 姆克儿 → 姆克鸟 → 姆克鹰
    - 可达鸭 → 哥达鸭
    - 乌波 → 沼王
    - 溜溜糖球 → 雨翅蛾
    - 龙虾小兵 → 铁螯龙虾
    - 角金鱼 → 金鱼王
    - 太阳珊瑚无进化
  - 合计约 36 个模型，分批完成。
- **精细化标准**
  - 面数目标：初始形态 8–12k，最终形态 12–15k。
  - 建模时允许先做到更高精度，导出前超过 15k 的模型用 Blender Decimate（Collapse，保留 UV 和顶点色边界）降到 15k 以内，再检查轮廓。
  - 细节要求：
    - 手指、爪子、牙齿用实体几何，不用贴片；
    - 眼睛有内凹眼窝、虹膜和高光；
    - 耳朵、鳍、翅膀有厚度；
    - 分色边界尽量走拓扑线。
  - 本次 17 种和早期的 23 种按此标准逐只复查，在模型展示台标记后返工。
  - 现在最高的是 724 狙射树枭，约 11.4k，还没有超过 15k 的模型。

## 九、树果 / 素材采集 / 种植 / 培育家职业 / 能量方块（2026-10-03 补充）

> 现状：道具表里只有 3 种树果（文柚果、橙橙果、木子果），只能在商店买和战斗中携带使用。野外没有采集点，也没有种植系统。

### 9.1 树果（约 24 种）

| 类别 | 树果 | 用途 |
|---|---|---|
| 回复 | 橙橙果、文柚果、苹野果（PP） | 携带，HP 低于一半时自动食用 |
| 状态 | 樱子果（麻痹）、零余果（睡眠）、桃桃果（中毒）、莓莓果（灼伤）、利木果（冰冻）、木子果（全部） | 携带自动治疗 |
| 降努力值 | 榴石果、藻根果、香蕉果、哈密果、葡萄果、茄番果 | 降低对应能力的努力值，同时提升亲密度（培育家必备） |
| 半减 | 巴巴果（水）、吃吃果（电）、霹霹果（草）等 6 种 | 抵挡一次效果绝佳的伤害 |
| 风味 | 蔓莓果、勿花果、异奇果等 | 主要作为能量方块原料（辣 / 涩 / 甜 / 苦 / 酸） |

- 每种树果有 5 维风味值和顺滑度，决定做出来的能量方块品质。
- 野外树果树按生态分布：草原多回复类，湖畔和河口多状态类，高地多降努力值类，幻影之森在夜晚出稀有风味果。

### 9.2 野外采集

| 采集点 | 位置 | 产物 | 条件 |
|---|---|---|---|
| 树果树 | 各野区（每区 6–10 棵） | 树果 1–4 个 | 摘完后按游戏天数重新结果（1–3 天） |
| 草药丛 | 草原、林缘、蒲婆婆家后山 | 药草、清香草（可做回复药） | 每日刷新 |
| 贝壳滩 | 西岸沙滩、河口 | 贝壳、珍珠、心之鳞片（稀有） | 退潮时（游戏时间早 / 晚）才露出 |
| 蘑菇圈 | 幻影之森 | 小蘑菇、大蘑菇、发光蘑菇（夜） | 夜晚 / 雾天产量翻倍 |
| 矿点 | 澜源高地、海崖 | 碎石、硬石、进化石（稀有） | 需要「碎岩」 |
| 蜂蜜树 | 林缘 | 甜甜蜜 | 涂在树上 6 小时后吸引稀有宝可梦 |

- **交互**：靠近采集点会出现提示，按 E 采集。采集时播放 1 秒动作，掉落物飞入背包，并弹出提示。
- **跟随宝可梦协助**：
  - 草系：采草药时额外 +1；
  - 岩石 / 格斗系：采矿时额外 +1；
  - 嗅觉好的宝可梦（如蛇纹熊）：每天随机「捡到」道具。
- **刷新与存档**：每个采集点有固定 id，存档只记录上次采集的游戏日。

### 9.3 种植

- **田地**：
  - 萌芽镇自家后院有 4 块，完成教学任务后开放；
  - 翠澜镇、港湾市各有 6 块公共田；
  - 培育家等级提升后扩建，最多 16 块。
- **生长阶段**：种子 → 发芽 → 长高 → 开花 → 结果，按游戏内小时推进。不同树果需要 8–48 游戏小时（游戏 1 天约等于现实 24 分钟，以 `clock` 为准）。
- **养护**：
  - **浇水**：喷壶。每个阶段至少浇一次，否则产量减少；下雨天自动浇水。
  - **肥料**：
    - 成长肥：时间 −25%；
    - 丰收肥：产量 +2；
    - 恒久肥：水分保持更久；
    - 变异肥：有概率长出稀有树果。
  - **杂草 / 虫害**：随机出现，需要手动清除，或交给虫 / 草系宝可梦处理。
- **收获**：产量 2–6 个，受浇水次数、肥料和天气影响。
- **视觉**：每种树果有专属低多边形植株，结果期挂出对应颜色的果实。田地显示湿润 / 干燥的土色差别。

### 9.5 能量方块等新物品

- **能量方块（宝可方块）**
  - 在方块机里放 2–4 种树果，玩一个转盘节奏小游戏：按准时机提高顺滑度和等级。
  - 方块有 5 维风味、等级和顺滑度。
  - **用途**：
    - 喂食宝可梦：提升亲密度，以及对应外观状态（帅气 / 美丽 / 可爱 / 聪明 / 强壮）。合口味的性格加成翻倍，讨厌的口味效果减半。
    - 野外诱饵：放在地上 3 分钟内，偏好该口味的物种出现率提升（按物种性格倾向表）。
    - **安抚霸主**：投喂合口味的方块会降低霸主的敌意，战斗开场不再获得能力提升，捕获率略有提高。
  - 存储：背包新口袋「方块盒」，容量 40 个。
- **料理**（与方块共用风味体系，后期）：营火做树果料理，效果是一段时间内某类宝可梦出现率提高，或者经验 +10%。
- **工具与素材道具**：
  - 工具：喷壶、金色喷壶、树果袋、采集篮（掉落 +1）；
  - 肥料：4 种；
  - 诱物：甜甜蜜；
  - 素材：药草、清香草、贝壳、珍珠、蘑菇 3 种、碎石、硬石、心之鳞片、霸主之鳞；
  - 性格薄荷：21 种，按性格合成。
- **合成**：在宝可梦中心旁的「工坊」用素材合成回复药、精灵球（硬石 + 树果 → 自制球）、肥料和薄荷，配方随培育家等级解锁。
