# ART-002 · 模型规范

适用：宝可梦、人物（玩家 / NPC / 馆主）、骑乘。场景道具另见文末。设计依据：设计文档 §6、§8.4。
**所有模型、贴图、动画都必须手工制作**，不得使用从官方游戏中提取的资源。

## 1. 坐标与尺寸

| 项 | 规定 |
|---|---|
| 单位 | 1 单位 = 1 米 |
| 朝向 | 正面朝 **+Z**，上方为 +Y（glTF 标准；Blender 导出时勾选 +Y Up） |
| 原点 | 两脚之间的地面，脚底在 y = 0；飞行 / 漂浮类原点仍放在地面投影点，悬浮高度用 `root` 骨骼动画表达 |
| 尺寸 | 按图鉴身高（`species.json` 中的 height）建模；运行时允许 ±30% 的视觉缩放（在 `ModelManifest.scale` 中配置，禁止改模型本身） |
| 变换 | 导出前应用全部变换（Apply All Transforms），根节点的缩放为 1、旋转为 0 |

## 2. 面数、贴图、材质

| 档 | 范围 | 三角面 | 贴图 | 动画 |
|---|---|---|---|---|
| S | 御三家全进化线、馆主王牌、神兽、剧情宝可梦（约 40 种） | ≤ 15k | 1024² ×1 | 10 个（下表全部） |
| A | 其余全部 | ≤ 8k | 512² ×1 | 8 个（不含 `idle_alt`、`ride`） |
| 人物 | 玩家 / 馆主 | ≤ 12k | 1024² | 人物动画集 |
| 人物 | 普通 NPC | ≤ 6k | 512² | 人物动画集 |

- 远景 LOD1：面数约为原模型的 40%，文件后缀为 `_lod1`（可选；没有 LOD1 时运行时只做距离剔除）。
- 材质：每个模型**最多 2 个材质**（主体 + 需要透明的部分，如翅膀膜、火焰）；运行时会统一替换成 Toon 材质，只保留 `baseColorTexture`、`baseColorFactor` 和 `alphaMode`。
- 贴图：平涂色块，sRGB；不画明暗。眼睛做单独的 UV 岛，方便做眨眼 / 表情贴图偏移。
- 描边：模型不需要自带描边；运行时自动生成反向外壳。**必须闭合**（不留开口与重叠面），否则外壳描边会破。
- 异色：同一套 UV，另画一张贴图 `<id>_shiny.png`（KTX2 压缩后为 `.ktx2`）。

## 3. 骨骼命名

统一英文小写，下划线分段，左右后缀 `_l` / `_r`。按体型选模板，缺失的骨骼省略，**不得改名**。

| 骨骼 | 用途 | 必需 |
|---|---|---|
| `root` | 地面根骨，位移 / 悬浮 | ✔ |
| `hips` → `spine` → `chest` → `neck` → `head` | 躯干链 | `hips` `head` ✔ |
| `jaw`、`eye_l/r`、`ear_l/r` | 表情 | |
| `shoulder_l/r` → `arm_l/r` → `forearm_l/r` → `hand_l/r` | 前肢 / 手 | |
| `thigh_l/r` → `shin_l/r` → `foot_l/r` | 后肢 / 腿 | |
| `wing_l/r` → `wing_tip_l/r` | 翅膀 | |
| `tail_01` … `tail_NN` | 尾巴链 | |
| `fin_*`、`extra_*` | 特殊部位（如火岩鼠的背火） | |
| `socket_mouth`、`socket_hand_r`、`socket_back`、`socket_fx` | 挂点：招式特效与骑乘鞍座 | `socket_fx` ✔ |

- 体型模板：双足、四足、鸟类、鱼类 / 蛇形、漂浮。模板文件放在 `assets/models/_rigs/`。
- 每个顶点最多受 4 根骨骼影响；骨骼总数不超过 64 根。

## 4. 动画片段

片段名必须完全一致（动画状态机按名字查找）。全部为**原地动画**，位移由代码控制。

| 片段 | 循环 | 时长 | 说明 | S | A |
|---|---|---|---|---|---|
| `idle` | ✔ | 2–4 s | 待机，战斗与大地图共用 | ✔ | ✔ |
| `idle_alt` | ✘ | 3–6 s | 待机小动作（伸懒腰、理毛） | ✔ | |
| `walk` | ✔ | 约 1 s | 1.6 m/s 时脚不打滑 | ✔ | ✔ |
| `run` | ✔ | 约 0.6 s | 5–7 m/s | ✔ | ✔ |
| `attack_physical` | ✘ | 0.8–1.2 s | 在第 50–60% 处加 glTF 事件标记 `hit`（导出为片段 extras 中的 `hitTime`） | ✔ | ✔ |
| `attack_special` | ✘ | 1.0–1.5 s | 同上；特效从 `socket_fx` 发出 | ✔ | ✔ |
| `hit` | ✘ | 0.4 s | 受击 | ✔ | ✔ |
| `faint` | ✘ | 1.2 s | 倒下，**最后一帧保持** | ✔ | ✔ |
| `sleep` | ✔ | 3 s | 睡觉，也用于大地图夜间 | ✔ | ✔ |
| `ride` | ✔ | 1 s | 骑乘姿势（仅骑乘宝可梦） | 骑乘 | |

飞行 / 水栖类用 `fly` / `swim` 代替 `walk` / `run`（可选）；状态机找不到对应片段时回退到 `walk`。
人物动画集：`idle`、`walk`、`run`、`jump`、`throw`（扔球）、`talk`、`wave`、`ride_sit`、`surf_stand`。

## 5. 文件与导出

- 路径：`assets/models/pokemon/<全国编号3位>_<英文小写>.glb`，例如 `722_rowlet.glb`；人物为 `assets/models/characters/<id>.glb`。
- 源文件（`.blend`）放在 `art-source/`（不进构建，走 Git LFS）。
- Blender 导出 glTF 2.0：格式 GLB；+Y Up；应用修改器；只导出选中；动画勾选 NLA Tracks；关闭“始终采样动画”（减小体积）；不导出相机与灯光。
- 压缩：`gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress ktx2`（几何用 Meshopt，贴图用 KTX2 / UASTC）。解码器已随构建发布（`assets/_decoders/`）。
- 体积：S 档 ≤ 1.5 MB，A 档 ≤ 600 KB（压缩后）。

## 7. 场景道具

- 树 / 岩石 / 灌木：≤ 2k 三角面，共用 512² 调色板贴图，使用实例化渲染；原点在底部中心。
- 建筑：LOD0 ≤ 6k，LOD1 ≤ 1.5k；门的位置加空节点 `door`（交互点）。
