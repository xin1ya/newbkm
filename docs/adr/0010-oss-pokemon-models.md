# 0010 · M3 起宝可梦模型以开源模型为底

- 日期：2026-10-05
- 状态：已采纳（用户决定）
- 修订：ADR 0005（全部手工制作）、设计 §8.1（不使用官方提取模型）、§8.2

## 背景
M1–M2 的 120 个宝可梦模型全部由 AI 助手驱动 Blender 脚本手工制作，并以 pokemon-3d（github.com/rcghpge/pokemon-3d）为形体参考，做了 ≥0.70 剪影重合度验收。手工制作是项目关键路径（R-01）。M3 需要两座岛的新物种，用户决定改用开源模型为底，只调整着色与骨骼动作。

抽查（25 / 95 / 145 / 637）：多数带蒙皮骨骼，但骨骼名与数量各不相同（18–54 根），部分没有骨骼，基本没有可用动画；三角面 1.9k–11.5k；贴图 2–4 张。

## 决定
1. M3 起新物种以 pokemon-3d `models/regular/<id>.glb` 为底，保留网格与贴图。
2. **丢弃原骨骼与动画**，按本项目标准骨骼（biped / quadruped / serpent / rigid / larva / bird …，命名见 `docs/art/model-spec.md`）重新绑定、自动权重，复用现有 9 段程序化动画（idle / idle_alt / walk / run / attack_physical / attack_special / hit / faint / sleep，必要时 fly / swim）。
3. 着色改为项目 Toon 材质：贴图色阶量化为平涂色块，异色用调色贴图。
4. 规格不变：朝 +Z、脚底 y=0、按图鉴身高缩放、≤15000 三角形、glb + meta。
5. 仓库保持私有、仅内部学习、不公开发布；模型文件进 git。asset-tracker 中登记来源为「OSS 转换」。
6. M1–M2 的 120 个手工模型保持不变。

## 后果
- 模型产能大幅提高，M3 不再被模型制作卡住。
- 风险：提取模型版权属于原权利人；任何公开发布前必须整体替换（与设计 §8.1 的「公开前替换」原则一致）。
- 自动权重在细长部件（尾巴、翅膀、触手）可能需要逐只修正，转换管线需输出对比渲染图供人工确认。
