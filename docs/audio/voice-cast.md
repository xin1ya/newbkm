## 流程
1. `pnpm tsx scripts/extract-voice.ts` → `docs/audio/voice-lines.json`（id = `voiceId(text)`，FNV-1a）。
2. 按音色分组整段合成（每段 ≤1500 字），`scripts/voice/vfinal.py <voice>`：vosk 识别时间戳对齐 + 时长 DP 兜底切句，RMS 归一，输出 mp3 56k。
3. 打包到 `assets/audio/voice/<id>.mp3` + `manifest.json`。
4. 运行时 `core/audio/voice.ts`：Dialog / 旁白每页按文本查表播放；场景（室外/室内/道馆/梦境）与语气（感叹/省略/心声）调整音量、混响、滤波；播放时压低 BGM 与环境音。
