## 4. QA 中发现并修复的问题

### 性能
| 问题 | 修复 |
|---|---|
| 性能路线从 M1-13 起跑在自家二楼室内（新游戏开场梦境），报告的「达标」是假数据（三角面仅 12k） | 路线使用 `?quick` 跳过开场；新增防回归断言：三角面峰值 > 200k、野生刷新 > 0 |
| 性能路线用遇敌冷却屏蔽战斗，冷却期间 SpawnManager 不刷新，野生宝可梦从未计入 | 改为吞掉遇敌事件 / 草丛判定，保留刷新 |
| 真实数据：high 三角面峰值 1.578M 超预算 | ①草 / 花细节格密度 LOD（实例按确定性哈希打乱，远于 55% 可视距离只画一半）；②宝可梦模型恢复视锥剔除（绑定姿势包围球 ×1.6，此前整只关掉剔除，屏幕外也绘制）；③野生宝可梦远近细节（>30 m 关描边外壳与投影，滞回 26 m）；④成群刷新不得突破同屏上限 → **1.109M** |

### 游戏内
| 问题 | 修复 |
|---|---|
| 御三家选择卡片的徽标是方块叠字 | 徽标 / 属性标签样式只在打开暂停菜单时注入；改为 `monIcon` / `typeChip` 首次使用时注入 |
| 章节结尾卡上叠着任务提示 | 全屏演出（章节卡、梦境旁白）期间隐藏任务提示 |
| 御三家选择时任务追踪面板压住右侧卡片 | 选择界面期间隐藏追踪面板 |
| 战斗中小型宝可梦（木木枭 0.55 m）过小 | 战斗展示放大到最低 0.85 m（上限 ×1.7），借用的模型战后恢复 |

### 用例
| 问题 | 修复 |
|---|---|
| 开发机缺少 Playwright 浏览器 | `pnpm exec playwright install chromium chromium-headless-shell` |
| 钓鱼 / 封锁点用例使用旧的道馆桥头封锁坐标 | 更新为 `[31.5, -55]` 半径 2.5 |
| 开场用例首次点击被梦境旁白层拦截 | 聚焦画布用 `force` 点击 |
| 研究所出门用例：按住 S 会再次走回门里 | 在 `interior:leave` 事件里记录室内标记 |
| 道馆木筏 / 室内存档：固定时长按键在慢机器上差几厘米 / 被忙碌帧吞掉 | 改为轮询 / 重试 |
| 12 路并发软件渲染导致计时类断言轮流偶发失败 | worker 限为 6（`PW_WORKERS` 可覆盖），smoke 失败重试 1 次并报告为 flaky |
