# 翠澜群岛（Cuilan Archipelago）

3D 半开放世界宝可梦同人 RPG。**内部学习项目，仓库私有，不公开发布。**

- 👉 **先读 [docs/00-MASTER-CONTROL.md](docs/00-MASTER-CONTROL.md)**：进度、任务、代码导航、协作规范
- 现行设计：[docs/2026-09-29-cuilan-archipelago-3d-semi-open-world-design.md](docs/2026-09-29-cuilan-archipelago-3d-semi-open-world-design.md)

## 快速开始

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # 类型检查 + 构建到 dist/
```

要求 Node ≥ 20、pnpm ≥ 9。
